# Sequences

Finished story sequences, one folder each, named `YYYY-MM-DD_soft_<topic>` or `YYYY-MM-DD_hard_<topic>`.

Inside each one:
- `sequence.md`: the brief, the arc, and every frame's copy, plus what to add in the app when posting (polls, links, keyword)
- `export/`: **the PNGs to post** (1080×1920), plus `_preview.png` showing the whole sequence at a glance
- `frames/`: the HTML each frame is designed in (Claude edits these for changes)

`_template/` is the starting point Claude copies for each new sequence.
