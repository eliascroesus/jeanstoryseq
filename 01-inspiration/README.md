**Tips**
- Screenshots of full sequences are the most useful. To keep one sequence's frames together, name them alike (`creator-topic-01.png`, `creator-topic-02.png`…) or drag the whole folder in.
- Copy-only references work too: paste the text into a `.md` or `.txt` file and upload it.
- A note in the filename about why you like it helps: `hook-is-insane-01.png`.
